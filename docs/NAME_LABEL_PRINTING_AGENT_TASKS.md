# 学生姓名贴生成与打印：开发 Agent 任务书

> 依赖文档：[架构文档](NAME_LABEL_PRINTING_ARCHITECTURE.md)。所有任务必须遵守项目 `AGENTS.md`；未说明的产品扩展不得自行加入。

## 0. 交付约束

- 目标平台仅为 Web；使用 React 19、TypeScript、Vite、Tailwind v4、React Router、Zustand 与 shadcn/ui 按需组件。
- 功能路由为 `/tools/name-labels`，页面只负责组合，业务代码必须位于 `features/label-printing/`。
- 姓名、原始文件名和导入内容不得写入 URL、控制台、日志、分析事件、`localStorage`、`sessionStorage` 或网络请求。
- 新依赖分两类并保持最小化：NL-00 可按需加入 shadcn/ui 基础组件所需依赖与测试工具链；功能运行时仅加入经过确认的 `react-to-print` 与 `read-excel-file`。安装前检查当前依赖，并在变更说明记录用途、版本与许可证。
- 不复制 GPL、未授权或许可证不清晰的参考仓库代码。
- MVP 只实现教师批量姓名贴；姓名为必选字段，班级为一次性导入的可选字段；班级管理、学号、单人铺满、桌牌、拼音、卡通主题、背景上传、保存数据和 PDF 输出均不得提前实现，详见架构文档第 4.5 节。

### NL-00｜工程基线、UI 基础与测试工具链

**目标**：在业务开发前解决基础 UI、测试和版本基线缺失的问题，使后续任务不为测试或对话框临时改变架构。

**修改范围**：根/应用脚本、测试配置、`components/ui/`、全局样式、`app/App.tsx` 的 Provider 挂载，以及必要的 shadcn 配置文件。

**实现要求**：

- 先记录并独立提交当前基础工程基线；功能开发不得与未跟踪的初始化文件混在同一提交中。
- 检查并按需初始化 shadcn/ui，最少提供任务实际需要的 Button、Dialog、Input、Select、Tabs、Tooltip 与 Sonner 挂载；不引入第二套 UI 组件库。
- 建立最小语义设计 token：`surface`、`text`、`border`、`primary`、`error`、`success`、`focus`，并维持 4px/8px 间距节奏。业务组件不得散落色值。
- 配置 Vitest、React Testing Library 与 Playwright，并在根脚本提供 `test`、`test:coverage`、`test:e2e`；测试依赖只服务于当前 Web 应用。
- 恢复 `@typescript-eslint/no-unused-vars` 为错误；`react-hooks/exhaustive-deps` 至少为警告。现有豁免若确有必要，必须在局部代码说明原因。

**验收**：基础工程基线可追溯；一个 Button/Dialog 测试和一个浏览器 smoke test 可运行；`pnpm build`、`pnpm lint` 与新增测试命令均有真实结果。

### NL-02｜纯布局计算、参数校验与测试

**进度状态**：以第 1 节进度看板为准。

**依赖**：NL-01、NL-00。

**目标**：实现屏幕与打印共用的、以毫米为单位的分页算法。

**修改范围**：

- `features/label-printing/utils/layout.ts`
- `features/label-printing/utils/validation.ts`
- 对应单元测试文件（按项目最终测试工具命名）。

**实现要求**：

- 实现 `validateLayout(candidate)`，返回字段级错误而非仅布尔值；校验有限数值、整数行列、正尺寸/间距、页边距、起始格范围与网格容纳关系。
- 实现 `createPageLayouts(names, paper, layout)`，仅接收已验证的领域对象，并依据架构文档第 8.1 节公式生成 `PageLayout[]`；非法候选由验证层以结果对象返回，不抛出未处理异常。
- 以 `firstLabelIndex` 填充首张纸的空格；第二页及之后从第 0 格开始；末页空格明确表示为 `empty`。
- 布局数据必须包含页尺寸、cell 行列号、绝对位置和对应姓名，不让 UI 重新计算位置。
- `offsetXmm`、`offsetYmm` 只在最终位置应用；布局能否容纳不得受偏移影响。
- 无姓名返回空页数组；`PageLayout` 的 cell、页尺寸、位置与姓名引用均为不可变计算结果，UI 不重新计算位置。

**最低测试集**：A4 2×8 单页、跨两页、起始格为中间位置、首格/末格边界、横向纸张、超出可用面积、中文与长姓名、空名单。

**验收**：测试可重复运行，布局结果可由独立 TypeScript 测试验证，不依赖 DOM；测试工具不在本任务临时引入。

### NL-03｜模板预设、Zustand 草稿状态与隐私边界

**进度状态**：以第 1 节进度看板为准。

**依赖**：NL-02。

**目标**：实现“最后有效领域草稿 + 原始表单输入”的双层状态、非敏感模板设置与严格的名单隐私边界。

**修改范围**：

- `features/label-printing/utils/templatePresets.ts`
- `features/label-printing/stores/useLabelPrintingStore.ts`
- `features/label-printing/hooks/useLabelPrintingDraft.ts`

**实现要求**：

- 提供架构文档规定的四种通用 A4 预设与自定义模板；预设数值可编辑。
- 将模板定义为卡片数据：稳定 `id`、纸张与 mm 布局、列×行、每张数量、固定双字段说明、适用说明和实物验证标记。初版包含 2×8、3×8、4×10、3×8 双字段和自定义；未验证模板不得声称匹配特定厂商纸型。
- Store action 至少包括 `setNames`、`selectTemplate`、`restoreSelectedTemplateDefaults`、`updatePaper`、`updateLayout`、`updateAppearance`、`setPreviewScale`、`resetDraft`。恢复模板默认参数不得清空姓名或起始空白格。
- `useLabelPrintingDraft` 以字符串保存编辑中的字段、触碰状态与字段错误；只有通过 `validateLayout` 的数值才调用 store 更新领域草稿。非法编辑期间，预览使用最后一次有效的 `PageLayout[]`，不能清空姓名或向布局函数传入 `NaN`。
- 不在 store middleware 中加入持久化姓名数据。若实现“记住设置”，只保存纸张、布局、外观与版本号，且写入前显式构造 allowlist 对象。
- `resetDraft` 必须恢复安全默认模板并删除内存中的姓名。

**验收**：模板卡显示列×行、每张数量、双字段说明与验证状态；恢复当前模板默认参数后，姓名和起始空白格不变；输入非法数值时保留最后有效预览且显示字段错误。用浏览器开发工具确认修改姓名后没有新增存储键、没有网络请求、刷新后姓名消失；非敏感设置若实现持久化，刷新后可恢复。

### NL-04｜CSV/XLSX/文本导入与名单清洗

**进度状态**：以第 1 节进度看板为准。

**依赖**：NL-01、NL-03。

**目标**：把所有输入渠道归一为带源行号的 `StudentName[]`；姓名列必选，班级列可选。

**修改范围**：

- `features/label-printing/services/importNames.ts`
- `features/label-printing/hooks/useLabelImport.ts`
- `LabelImportPanel.tsx`、`NameColumnPicker.tsx`、`NameListPreview.tsx`
- `workers/parseWorkbook.worker.ts`（仅在主线程测量显示明显卡顿时创建）、必需的新依赖与锁文件。

**实施前检查**：先检查 `apps/web/package.json` 是否已有可用解析能力。当前 XLSX 解析使用 MIT 的 `read-excel-file@9.3.10` 浏览器入口；只在文件导入时动态加载，并在变更说明记录版本、许可证和最终产物体积。CSV 继续使用 feature 内的受限解析器，不另加 CSV 解析库。

**实现要求**：

- 支持多行粘贴、CSV、XLSX 第一个工作表；CSV 支持常规带引号字段，不能用简单 `split(',')` 代替解析器。
- 只接受 CSV/XLSX；导入前拒绝大于 5 MB 的文件，解析最多 10,000 行、100 列。超过限制、损坏文件或不支持格式时，错误不得含姓名/原始表格内容，且不改变当前草稿。
- 表格导入显示列名及最多 5 个非敏感示例值，用户显式选择姓名列和可选班级列后才写入草稿。
- 清洗：去首尾空白/不可见空格、NFC 规范化、移除空行、姓名和班级值分别限制最大 80 字符、保留原始行号；班级空值保持为空。
- 同名记录默认保留并标记重复，不能静默去重。
- 解析失败或列选择取消时保留原草稿；错误说明原因和可操作的恢复方式。
- 文件读取只用 File API，不上传文件；错误对象不可包含姓名或原始表格内容。
- 对 1,000 行和接近上限的 XLSX 测量解析与输入响应；若主线程出现明显卡顿，将解析移入 feature 私有 Worker，Worker 只处理当前内存中的受限数据。

**验收**：使用中文姓名、英文姓名、空行、重复值、带引号的 CSV、两列 XLSX、只含姓名的表格、超限文件与损坏文件进行手工检查；确认班级/姓名都显示在标签中，并验证两个标题可以分别关闭；导入后没有网络请求与持久化学生信息。

### NL-05｜真实尺寸预览与可打印文档

**进度状态**：以第 1 节进度看板为准。

**依赖**：NL-02、NL-03。

**目标**：由同一 `PageLayout[]` 渲染屏幕预览和打印内容。

**修改范围**：

- `PrintPreview.tsx`
- `PrintableLabelDocument.tsx`
- `styles/print.css`

**实现要求**：

- 屏幕预览可缩放，缩放通过外层 CSS transform 实现，不修改 mm 领域数据。
- 可打印文档以 `paper.widthMm`、`paper.heightMm` 建立每一页，cell 使用稳定 id 与 mm 定位。
- 姓名和可选班级一律作为文本节点输出；两个字段按班级在上、姓名在下显示，字段标题分别由 `showClassTitle` / `showNameTitle` 控制；每个字段固定占一行，字段内不自动换行，过长内容使用省略号并保留完整 `title`。
- 模板只描述纸张几何和双字段适用场景；标签内容固定为姓名一行，或班级 + 姓名两行，不能通过运行时自动换行改变字段语义。
- `@media print` 隐藏导航、配置面板、缩放控件、辅助线和屏幕专用提示；只打印姓名贴文档。
- `@page`、纸张方向、打印 document 标题和背景图形提示符合架构文档第 8.3 节。
- 若布局无效或名单为空，不渲染可打印内容，不允许打印按钮可用。

**验收**：预览页数/起始空白格与 NL-02 单元测试一致；浏览器打印预览不出现应用 Header、按钮或输入框。

### NL-06｜配置面板、页面组合与响应式体验

**进度状态**：以第 1 节进度看板为准。

**依赖**：NL-03、NL-04、NL-05。

**目标**：形成完整教师工作台，不把所有控件堆在一个无层级表单中。

**修改范围**：

- `NameLabelPrintingPage.tsx`
- `LabelTemplatePanel.tsx`、`LabelContentPanel.tsx` 与必要的 feature 子组件。
- 仅在缺少时，按项目规范添加 shadcn/ui 组件源码。

**实现要求**：

- 桌面 `>=1024px` 为“左配置、右预览”，右侧打印主操作始终明显；中小屏纵向排列。
- 空状态加入可跳转、非锁定的四步工作流提示：录入名单、选择标签纸、调整样式、打印 A4。它只能帮助理解流程，不能阻止教师回退修改前面的面板。
- 标签纸面板首先显示模板卡片库；卡片包含缩略网格、列×行、每张数量、双字段说明、适用说明和实物验证状态；不显示伪精确的使用次数或热度。
- 配置按“名单与导入 / 标签纸与排版 / 内容与样式 / 校准”分组，使用渐进披露，初次进入不展开不必要的高级参数；参数区提供“恢复当前模板默认参数”，并说明该操作保留姓名名单和起始格。

## 4. 统一完成定义

任一任务仅在以下条件都满足时可标记完成：

- 改动被限制在任务范围内，无无关重构。

- 导入文件、行列数和文本长度均受到既定上限约束；失败或超限不泄露原始内容。
- 相关自动化测试、构建和 Lint 已运行并报告真实结果。
