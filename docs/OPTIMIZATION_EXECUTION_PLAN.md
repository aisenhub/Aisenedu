# Aisenedu 优化执行计划

> 状态源：本文件第 2 节为本轮优化的唯一进度来源。实施 Agent 每次开始、阻塞、完成或发现回归时，必须立即更新该表；不要只在聊天中报告。关联既有 MVP 任务的回归，还必须同步更新 [学生姓名贴任务书](NAME_LABEL_PRINTING_AGENT_TASKS.md)。

## 1. 执行边界

- 本轮目标是提升姓名贴工具的安全性、响应式布局、可用性、无障碍、视觉一致性、打印可靠性与性能；不得重写应用或提前实现云端名单、班级管理、学号、拼音、桌牌、单人铺满或 PDF 输出。
- 保持 React 19、TypeScript、Vite、Tailwind CSS v4、React Router、Zustand、shadcn/ui 的技术基线；遵循项目根目录 `AGENTS.md`。
- 所有 UI、布局、响应式、交互或可访问性工作开始前，检查项目内已有的 shadcn/ui 组件、Tailwind token 和页面规范，并遵循 375 / 768 / 1024 / 1440px 的验收要求。
- 新功能或新依赖必须先进行 GitHub 调研，评估维护状态、许可证、技术栈兼容性、包体积与安全性，并更新 `reference/REFERENCE_PROJECT_INDEX.md`。不复制许可证不明或不兼容的代码。
- 学生姓名、班级、原始文件名与导入内容不得写入 URL、日志、分析事件或网络请求；当前项目草稿可通过版本化 `localStorage` 自动恢复，临时背景图片与对象 URL 不持久化。
- 禁止通过页面根节点 `overflow-x-hidden` 掩盖布局问题；如预览需要横向查看，滚动必须只存在于明确提示的预览容器。
- 用户上传的标签背景图仅在当前浏览器会话内存中使用，不上传、不进入项目静态资源、不随模板配置保存；刷新页面、清空或替换图片后应释放本地资源。仅支持 PNG、JPEG、WebP 等位图格式，不接受 SVG、远程 URL 或可执行格式。
- 随机渐变必须由已保存的种子和调色板确定，保证预览、翻页、重渲染与打印结果一致；禁止在 React 渲染过程直接使用 `Math.random()`。
- 字体只提供本机字体栈和明确的回退说明，不下载或捆绑未授权字体；“楷体”须声明为依赖本机安装的候选字体与衬线回退。

### 状态更新规则

- `未开始`：尚未修改该任务涉及的文件、依赖或测试。
- `进行中`：已开始，但未达到全部验收标准；备注必须包含正在处理的范围和下一步。
- `阻塞`：无法继续；备注必须写清复现方式、已尝试的安全检查、需要的用户决定或外部条件。
- `已完成`：填写当地日期、关键文件、实际运行的命令和结果。例如：`2026-08-29｜PrintPreview.tsx、smoke.spec.ts；pnpm test:e2e、pnpm build 通过`。

## 4. 可执行任务包

### OPT-01｜安全替换 XLSX 解析器

**目标**：移除 `xlsx@0.18.5` 对任意用户上传文件的解析路径。现有包存在已披露安全风险，不能以单纯升级 npm 版本处理。

**涉及范围**：`apps/web/package.json`、`apps/web/src/features/label-printing/services/importNames.ts`、导入单元测试、`reference/REFERENCE_PROJECT_INDEX.md`。

**实施步骤**：

1. 先调研至少两个维护中的浏览器端解析方案，记录许可证、安全公告、浏览器兼容性、动态加载体积、TypeScript 支持和实际采用/放弃理由。
2. 以最小依赖替换当前解析器；保留动态 import，禁止将解析库打入首页首屏 bundle。
3. 保持当前数据规则：5MB、10,000 行、100 列、80 字符、只读取第一工作表、姓名必选、班级可选、浏览器内存内处理。
4. 为损坏文件、超限文件、空工作表、无姓名列、超长文本和带班级列添加测试；重复内容按原样保留，不做检查或标记。
5. 在变更说明中记录依赖版本、用途和许可证。

**验收**：CSV、文本、XLSX 导入与列选择正常；异常文件有可恢复错误提示；新增依赖调研已记录；`corepack pnpm test`、`corepack pnpm build`、`corepack pnpm lint` 通过。

### OPT-02｜统一打印配置表单状态

**目标**：消除模板面板与校准面板各自创建 `useLabelPrintingDraft()` 所导致的输入、错误和可打印状态不一致。

**涉及范围**：`features/label-printing/hooks/useLabelPrintingDraft.ts`、`LabelPrintingWorkspace.tsx`、`LabelTemplatePanel.tsx`、`PrintCalibrationPanel.tsx` 及测试。

**实施步骤**：

1. 将单一表单会话提升到工作台根部，通过 feature 内 Context 或 Zustand 原子状态提供给子面板。
2. 使用函数式状态更新，避免读取旧 `form.errors`；保留“原始输入值”与“最后有效草稿”的双层行为。
3. 在失焦、切换模板和尝试打印时校验；无效配置应保留输入并指出修复方式。
4. 将打印姓名贴与打印校准页的禁用状态和原因传入对应按钮；不可出现看似可点击但无效的操作。

**验收**：跨面板修改即时同步；非法值不会破坏最后有效预览；修复错误后按钮恢复；单元与交互测试覆盖切换模板、非法值、撤销和打印门槛。

### OPT-03｜移动端工作台与预览重排

**目标**：修复 375px 已导入名单后的全局横向溢出，并建立移动端优先的工作流。

**涉及范围**：`LabelPrintingWorkspace.tsx`、`PrintPreview.tsx`、`LabelPageCanvas.tsx`、相关样式与 E2E 测试。

**实施步骤**：

1. 外层工作台从移动端单列开始；为网格和其子项补齐可收缩边界，例如 `min-w-0`，不要让纸张画布撑开文档根节点。
2. 手机端顺序固定为“导入 → 常用设置 → 预览 → 高级设置 → 打印”；仅在 `lg` 以上启用粘性预览。
3. 预览容器独立处理横向查看，提供“适应宽度 / 打印比例”切换，手机默认适应宽度。
4. 仅在预览实际可横向滚动时显示“左右滑动查看整张纸”提示；不得依赖用户猜测手势。
5. 校验固定或粘性元素不会遮住聚焦控件，横屏下仍能完成打印操作。

**验收**：375×812、667×375、768×1024、1024×768、1440×900 下均无页面根节点横向滚动；预览区可按设计独立滚动；长姓名、班级文本与错误提示不被裁切。

### OPT-04｜响应式与交互回归测试

**目标**：让自动化测试覆盖真实的已导入/已预览状态，避免空页面测试产生假阳性。

**涉及范围**：`apps/web/e2e/smoke.spec.ts`、必要的测试 fixture。

**实施步骤**：

1. 在每个断点先导入至少 3 条姓名，再断言 `document.documentElement.scrollWidth <= window.innerWidth`。
2. 覆盖 375、768、1024、1440px 及 667×375 横屏；覆盖长姓名、带班级、空名单和 1,000 人分页。
3. 断言预览的横向滚动发生在预览容器而非 `document`。
4. 补充键盘流程：跳过链接、错误修复、清空确认弹窗取消与 Escape。

**验收**：新增测试先在旧实现上能复现失败，修复后稳定通过；不得降低断言强度来使测试通过。

### OPT-05｜无障碍、焦点与动效修复

**涉及范围**：`FieldMessage.tsx`、`app/App.tsx`、全局样式、表单/导航组件与测试。

**实施步骤**：

1. 将帮助按钮的可点击区域扩大至至少 44×44px，保持可访问名称。
2. 路由切换后焦点移入 `main`；导航展示当前页状态。
3. 错误信息保留行内关联；避免每次键入均造成屏幕阅读器过度播报。
4. 将全局减少动效规则改为语义化动效 token，避免 `!important` 全量清零导致状态反馈缺失。
5. 检查对比度、键盘焦点、Dialog 退出、禁用状态和触摸目标。

**验收**：键盘可完成主流程；焦点始终可见；正常文本对比度至少 4.5:1；减少动效下不出现闪烁或失去状态反馈。

### OPT-06｜设计 token 与视觉系统统一

**目标**：形成“清晰、克制、低认知负担”的教育工具视觉系统。

**实施步骤**：

1. 基于项目现有 shadcn/ui 组件、Tailwind token 和页面规范确定组件、间距、字体、断点与状态方案，并在 `design-system/` 或 `docs/` 固化重要设计决策。
2. 定义并使用 surface、text、border、primary、danger、success、focus、阴影、圆角、间距与动效 token。
3. 将页面中直接使用的 `slate-*`、`blue-*`、`red-*` 逐步收敛至语义 token。
4. 本阶段明确采用浅色优先；深色模式作为独立任务，不能半实现。

**验收**：同类按钮、表单、卡片、提示与状态拥有一致视觉层级；没有新增业务组件硬编码色值；关键前景/背景组合通过对比度检查。

### OPT-07｜配置面板渐进式披露与预设

**实施步骤**：

1. 默认仅展示纸张模板、字号、对齐、预览与打印。
2. 将颜色、边框、圆角、标题开关、偏移等移入“高级样式/高级校准”。
3. 增加内置预设：`清晰标准`、`紧凑标签`、`大字易读`；预设须可被用户继续微调。
4. 每次预设或配置改变，实时显示预览与可能的打印风险。

**验收**：首次用户可不进入高级设置完成打印；高级设置可被键盘访问；切换预设不会清空名单或引入敏感数据保存。

### OPT-08｜打印前检查与恢复体验

**实施步骤**：

1. 增加打印前检查：名单数量、页数、纸张、边距、起始格、未修复错误。
2. 每个失败状态提供“原因 + 修复方法 + 重试入口”。
3. 校准完成后提供下一步指引；保留撤销清空、恢复默认模板与重试导入的明确路径。

**验收**：任一不可打印状态都有可理解的恢复路径；无效配置不能进入浏览器打印；成功操作有不抢焦点的反馈。

### OPT-09｜大名单性能测量与 Worker 化

**实施步骤**：

1. 测量 10,000 行、5MB 文件在导入、字段选择、预览分页时的主线程阻塞与输入响应。
2. 若解析或交互出现超过 100ms 的可感知阻塞，将 XLSX 解析移入 Web Worker；提供加载、失败与取消反馈。
3. 保持首页不加载工具解析依赖；仅进入工具并选择文件后加载。

**验收**：记录测量方法与结果；主流程无明显卡顿；没有姓名数据跨 Worker 生命周期之外保存或上报。

### OPT-10｜非敏感模板库与本地配置保存

**实施步骤**：

1. 调研并新增经过打印验证的标签纸模板；记录来源与采用理由。
2. 支持复制、重命名、导出与导入模板配置。
3. 保存前建立白名单，仅允许纸张、布局、样式和校准参数；严禁姓名、班级、文件名、导入内容。
4. 为本地存储键版本化，并提供删除全部本地模板设置的入口。

**验收**：导出的配置不含任何学生信息；导入恶意或损坏配置有校验与恢复提示；模板保存不影响当前未保存名单。

### OPT-11｜第二阶段能力调研与立项建议

**范围**：仅调研单人铺满、桌牌、拼音、主题模板等能力；不得实现班级管理、学号、云端名单保存。

### OPT-13｜样式数据模型与参考调研

**目标**：在实现字体、色盘、渐变和背景图前，先明确可打印、可测试且不持久化敏感数据的数据模型与依赖取舍。

**涉及范围**：`reference/REFERENCE_PROJECT_INDEX.md`、`docs/NAME_LABEL_PRINTING_ARCHITECTURE.md`、`features/label-printing/types.ts`、`templatePresets.ts`、store 与相关测试。

6. 更新架构文档的范围说明：允许本地、会话级、全标签共用的背景图编辑；不允许上传到服务端、持久化背景图或逐学生配置背景。

### OPT-14｜字体、色盘与确定性渐变边框

**目标**：提供可控、可打印且不会在预览与打印间变化的文字、边框和背景样式。

**涉及范围**：`LabelContentPanel.tsx`、`LabelPageCanvas.tsx`、样式 token、类型、预设和组件测试。

**实施步骤**：

1. 字体选择至少提供系统无衬线、系统衬线、楷体和等宽四类；楷体使用本机字体栈（如 `KaiTi`、`STKaiti`、`Kaiti SC`）并明确显示“依赖本机安装，缺失时回退为衬线字体”。禁止在线字体请求。
2. 将“文字颜色”“标签纯色背景”“实线边框颜色”改为可访问的色盘组件：内置常用色块、原生颜色选择器、HEX 输入与“恢复默认”。输入值标准化为安全的 `#RRGGBB` 格式，非法值不可进入打印草稿。
3. 增加边框模式：`纯色` 与 `本页随机渐变`。渐变模式从受控调色板和保存的种子派生每个标签的颜色；同一标签在预览、分页、缩放、重新渲染和打印中必须保持同一结果。“换一组渐变”只能显式更新种子。
4. 渐变边框使用不会改变标签实际 mm 尺寸的结构；圆角、边框宽度、背景图和打印 CSS 必须同时成立。不要依赖不同浏览器打印支持不稳定的纯装饰性技巧。
5. 文本、纯色背景和边框的预设组合须满足对比度要求；图片背景无法自动判定对比度时，显示可读性提示并提供 0–60% 的浅色/深色遮罩。

**验收**：选择楷体时预览与打印走同一字体栈；色盘可键盘操作并有可访问名称；渐变不闪烁、不因翻页而变化；固态、渐变、圆角和背景组合不会改变标签尺寸或造成溢出。

### OPT-15｜导入区字段标题与单行字段规则

**目标**：将字段标题选择放在用户定义数据含义的导入区域，并确保每个导入字段始终独占一行。

**涉及范围**：`LabelImportPanel.tsx`、`NameColumnPicker.tsx`、`LabelContentPanel.tsx`、`LabelPageCanvas.tsx`、类型、预设、导入/组件/E2E 测试。

**实施步骤**：

1. 从“内容与样式”移除“允许姓名和班级换行”开关和“字段标题”分组，删除对应类型字段、默认值、预设、测试及无效的 `maxLines` 截断逻辑。
2. 在 CSV/XLSX 的字段选择器中，在姓名列/班级列选择后提供“字段标题”分组：姓名标题始终可选；只有选择班级列后，班级标题才可选。确认字段选择时连同显示规则一起写入草稿。
3. 在多行文本导入区域提供姓名标题开关；无班级数据时不展示班级标题控制。已导入后仍可在“名单与导入”区域修改，不能把控制放回样式区域。
4. 标签渲染改为每个非空字段一个独立块级行：班级（如有）为第一行，姓名为第二行；字段内永不自动换行。长内容在该行内裁切并使用省略号，屏幕预览可暴露完整内容给辅助技术。
5. 增加实际预览溢出检测或等效的打印前校验；当字号、宽度或字段标题导致任一字段会被裁切时，明确告知用户，并提供“减小字号 / 关闭标题 / 使用更宽模板”的修复入口。
6. 将现有“三行内容”等文案调整为与固定双字段模型一致，不删除已经存在的标签纸尺寸模板，除非其几何参数本身失效。

**验收**：姓名与班级始终分别占一行；单字段名单只输出姓名行；字段标题只能在名单导入区域设置；长内容不会撑开、换行或导致页面横向溢出，且打印前有可恢复提示。

### OPT-18｜工作流布局与单主滚动重构

**目标**：用可回跳的四步工作流替代“左侧四张连续大卡片 + 独立滚动区”，保留实时预览优势，同时消除双层滚动、长表单和小高度屏幕下的操作迷失。

**涉及范围**：`LabelPrintingWorkspace.tsx`、`LabelImportPanel.tsx`、`LabelTemplatePanel.tsx`、`LabelContentPanel.tsx`、`PrintCalibrationPanel.tsx`、`PrintPreview.tsx`、feature 专属工作流组件/Hooks、Zustand UI 状态与 E2E/组件测试。

**工作流定义**：

| 步骤 | 标题 | 完成摘要 | 进入条件 |
| --- | --- | --- | --- |
| 1 | 导入名单 | `人数`、`是否含班级` | 始终可进入；姓名未导入时为当前必做项。 |
| 2 | 标签纸与排版 | `纸张`、`列 × 行`、`每页枚数` | 始终可进入；使用当前或默认模板。 |
| 3 | 内容与样式 | `字体`、字号、背景/边框状态 | 始终可进入；背景编辑作为本步骤的临时子模式。 |
| 4 | 校准与打印 | `X / Y 偏移`、页数、可打印/待修复状态 | 始终可查看；打印只在名单与布局有效时启用。 |

**实施步骤**：

1. 新建 feature 专属的 `LabelWorkflowStepper` 和工作流状态模型。`activeStep` 仅表示当前界面，不复制或重置已有草稿；“已完成/待处理/有错误”必须由名单、布局校验和打印状态派生。
2. 使用语义化 Tabs 或等效的步骤导航实现四个步骤。每个步骤按钮具有序号、名称、文字状态和摘要，不得仅用颜色区分；当前、完成和错误状态必须被辅助技术识别。
3. 允许用户随时回到任一已完成步骤修改。成功导入名单后自动建议或进入“标签纸与排版”，但不能锁住跳转；返回上一步时保留姓名、表单原始值、模板、样式和预览页码。
4. 桌面端（≥1024px）取消左栏 `max-height` 与 `overflow-y-auto` 的内部滚动。页面只保留主文档纵向滚动；顶部显示跨配置与预览两栏的紧凑步骤导航，下方左侧显示当前步骤内容，右侧保留粘性预览。预览允许的横向查看仍只限其自身容器。
5. 平板端（768–1023px）改为单列：顶部步骤导航自动换行，当前步骤内容在上、预览紧随其后，不保留任意面板独立纵向滚动。
6. 手机端（<768px）将四个步骤按钮排为不横向滚动的 2×2 网格；一次只显示当前步骤，预览紧随内容。名单与配置有效时，显示不遮挡焦点且包含安全区内边距的底部“打印姓名贴”操作条。
7. 将高级样式、高级校准和未来的背景编辑收敛为当前步骤内的二级折叠区。进入背景编辑时，只显示必要的背景控制并使右侧/下方预览进入“编辑背景”状态；完成或取消后返回步骤 3，编辑辅助线不进入打印 DOM。
8. 每个已折叠步骤显示可读摘要，例如 `28 人 · 含班级`、`A4 · 3 列 × 8 行`、`楷体 · 16pt`、`偏移 0 / 0 mm`；摘要中的用户文本需要可换行或截断后提供完整可访问名称。
9. 步骤切换后将键盘焦点移到当前步骤标题；若打印失败或多字段无效，激活对应步骤并聚焦现有错误摘要/首个无效字段。所有“上一步/继续”按钮点击区至少 44px。

**验收**：

- 不存在左侧或表单卡片的独立纵向滚动；鼠标滚轮、触摸滚动与键盘 PageDown 只推动主页面。
- 375、768、1024、1440px 以及 667px 横屏下，步骤导航、当前步骤、预览与打印操作均可达，无页面横向溢出。
- 导入、选择模板、修改样式、校准、返回任意步骤和打印前校验均保留用户已有输入。
- 键盘可依次进入步骤导航、当前步骤与预览控制；当前步骤、完成状态、错误状态和自动跳转均有清晰的可访问反馈。
- 背景编辑在本任务的布局基础上可嵌入步骤 3，不需要再次恢复旧的左侧长列表。

### OPT-16｜本地背景图编辑器与打印一致性

**目标**：允许用户在一张代表性标签预览中拖动、缩放和定位背景图，并将同一效果可靠地应用到当前全部标签及打印结果。

**涉及范围**：新增 feature 专属背景编辑组件和 Hook、`LabelContentPanel.tsx`、`LabelPageCanvas.tsx`、打印服务、store、样式和测试；不得放入通用 `components/ui/`。

**实施步骤**：

1. 在“标签背景”中提供“纯色 / 上传本地图片”选择；仅接受 PNG、JPEG、WebP，限制文件大小、解码像素数和异常图片错误。提示“图片不会上传，刷新页面后失效”。
2. 上传成功后打开或展开“编辑背景”区域，显示一个代表性标签边框。背景图的拖动和缩放只编辑该代表标签，但效果统一应用于本次打印的所有标签；本期不支持每张标签或每个学生单独编辑背景。
3. 支持鼠标和触摸 Pointer Events：在预览内拖动平移，使用等比缩放滑块、放大/缩小按钮、适应、填充、重置。缩放不得改变图片宽高比、标签几何或纸张尺寸；触摸之外必须有可操作的键盘/按钮替代方案。
4. 编辑态的选中边框、控制柄、提示和参考网格只能在屏幕预览中显示，绝不能进入打印 DOM。拖动时使用 Pointer Capture，避免与页面滚动冲突；小屏幕优先提供滑块和按钮，避免强制精细拖动。
5. 图片图层、遮罩、文字和边框的层级固定为：背景图 → 可读性遮罩 → 标签内容 → 边框。使用同一 `LabelBackgroundLayer` 渲染预览和可打印文档，避免两套样式分叉。
6. 在 `react-to-print` 的打印克隆环境中验证 object URL 图片加载和背景图形输出；打印前等待图片解码。若浏览器不能稳定打印 object URL，记录决策并采用有大小上限、仅会话内的替代表示，不能上传或长期保存图片。
7. 替换、清空名单、恢复默认或卸载组件时释放旧 object URL；模板本地保存、导出配置和错误日志中均不得包含图片二进制、object URL 或文件名。

**验收**：桌面和手机可在代表标签中完成上传、平移、缩放、适应、填充和重置；预览与打印使用同一背景位置；背景编辑不造成根页面横向滚动；刷新后图片消失且无残留资源；打印前明确提示浏览器需开启“背景图形”。
