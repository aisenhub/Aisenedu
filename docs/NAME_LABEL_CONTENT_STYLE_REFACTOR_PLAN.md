# 姓名贴“内容与样式”分类重构执行计划

**状态**：已实施（2026-08-31）
**范围**：`/tools/name-labels` 的“内容与样式”面板、外边框样式数据与对应预览/打印渲染。  
**已确认的产品决定**：一次只展开一个分类；圆角归属外边框；背景图片相关能力全部保留；外边框始终四边等宽，不提供逐边配置。

## 1. 目标与边界

当前面板将文字、颜色、外边框、内边框、背景图片和高级参数混在一个表单中，用户难以判断参数归属和影响范围。本次重构的目标是把样式设置变为可扫描、可逐项理解的分类工作流，同时继续保证预览和最终打印使用同一份配置。

本次只调整样式配置与外边框统一宽度逻辑，不改变以下内容：

- 名单导入、字段顺序、字段标题显示逻辑。
- 纸张、标签尺寸、行列、间距、起始格和打印校准。
- 标签内容自动适配、预览缩放、浏览器打印和本地草稿保存的总体机制。
- 背景图片上传、适应/填充、拖动定位、遮罩色调和遮罩透明度能力。
- 不新增渐变边框、逐边内框宽度、主题皮肤或新的第三方 UI 框架。

本计划已完成实现：已接入四类单开面板、五套配色预设、分类色盘、HEX 校验、低对比度提示、统一外框宽度渲染和旧版本地草稿迁移；预览与打印继续共用同一份外观配置。

实现继续使用项目内 React、Tailwind CSS 与 shadcn/ui 组件源码；先复用现有 Button、Select、Tooltip、Tabs 等组件，只有现有组件确实不满足时才按项目 `AGENTS.md` 的方式补充 shadcn/ui 源码。

## 2. 信息架构与交互

“内容与样式”保留标题、说明和“恢复默认样式”按钮，下面改为单开分类面板。默认展开“字体与文字”；用户打开新分类时，前一个分类自动收起。分类开合状态仅是当前页面 UI 状态，不写入打印配置或本地草稿。

每个收起的分类标题都显示当前配置摘要，避免用户必须逐项展开确认：

| 分类 | 标题摘要示例 | 展开后内容 |
| --- | --- | --- |
| 字体与文字 | `楷体 · 14 pt · 左对齐` | 字体、字号、行间距、字重、对齐、文字颜色、文字适配说明 |
| 外边框 | `已显示 · 0.25 mm · 圆角 1.5 mm` | 显示开关、外框颜色、统一宽度、圆角 |
| 内边框 | `已显示 · 实线` | 显示开关、内框颜色、线型 |
| 背景 | `纯色 · 白色` 或 `图片背景 · 已设置遮罩` | 纯色/图片方式、颜色、图片上传与定位、遮罩 |

分类标题使用可访问的按钮语义，带 `aria-expanded` 和关联的内容区域。键盘 Enter/Space 可展开或收起；同一时刻只能有一个内容区域处于展开状态。关闭外框或内框后，分类摘要改为“未显示”，其依赖参数在展开区域内隐藏或置灰，但已填写的值必须保留，以便重新打开时恢复。

## 3. 分类设计

### 3.1 字体与文字

直接呈现以下高频参数：

- 字体：系统无衬线、系统衬线、楷体（未安装时自动回退）、等宽字体。
- 字号：8–36 pt。
- 行间距：1–2 倍，步长 0.05。
- 字重：常规、中等、粗体。
- 对齐：左对齐、居中、右对齐。
- 文字颜色：使用“文字专属色盘”和自定义 HEX。

分类底部保留文字适配说明：空间不足时先压缩文字间距至 1 mm，仍不足才自动缩小字号。文字颜色与纯色背景的对比度不足 4.5:1 时显示非阻塞提示，提醒可能影响屏幕与打印清晰度；不限制用户保存自定义颜色。

### 3.2 外边框

外边框是标签最外层色带，设置项固定为：

- 显示开关。
- 外框颜色。
- 外框宽度：0–3 mm，统一应用至上、右、下、左四边。
- 圆角：0–10 mm。

删除“四边等宽”开关和上/右/下/左四个单独宽度输入框。关闭外框时预览和打印不渲染外层色带，外框颜色、宽度和圆角仍保留当前值；圆角继续应用于标签容器及内层裁切，保证视觉一致。

### 3.3 内边框

内边框负责标签内部的细线边界，设置项固定为：

- 显示开关。
- 内框颜色。
- 线型：实线、虚线。

内框线宽继续使用当前固定物理宽度 `0.2 mm`，不在界面新增线宽设置。关闭内框后，文字与外边框之间的最小安全间距逻辑必须保持正确，不应残留额外空白。

### 3.4 背景

背景分类采用两种背景方式：纯色和图片。可使用项目已有 Tabs；若 Tabs 不能满足当前布局，再使用清晰的分段选择控件，但不得再引入组件库。

- **纯色**：背景颜色色盘、HEX 输入、恢复该项默认色。
- **图片**：上传 PNG/JPEG/WebP、适应、填充、拖动定位、缩放、遮罩色调和透明度。
- 从图片切换到纯色时保留图片配置；从纯色切回图片时保留已上传图片和定位。背景图片对象 URL 仍不得写入本地草稿。
- 图片背景且遮罩透明度为 0 时，显示“建议开启遮罩以保证文字清晰度”的非阻塞提示。

## 4. 配色预设与色盘

颜色设置采用两层结构，避免把所有颜色混在一长排色点中。

### 4.1 整套配色预设

在四个分类面板之前增加“配色预设”区域。每张预设卡展示文字、背景、外框、内框四个微型色块及名称；点击后仅覆盖四个现有颜色字段：`textColor`、`backgroundColor`、`borderColor`、`innerBorderColor`。不得改变字体、字号、对齐、外框宽度、圆角、内框线型、背景方式、图片、定位和遮罩参数。

| 预设 | 文字 | 背景 | 外框 | 内框 | 使用场景 |
| --- | --- | --- | --- | --- | --- |
| 清晰蓝白（默认） | `#0F172A` | `#FFFFFF` | `#2563EB` | `#BFDBFE` | 日常彩色打印、课堂姓名贴 |
| 薄荷清新 | `#134E4A` | `#F0FDFA` | `#0F766E` | `#99F6E4` | 清爽、低刺激的班级场景 |
| 暖杏柔和 | `#7C2D12` | `#FFF7ED` | `#C2410C` | `#FED7AA` | 低龄教学、暖色主题活动 |
| 紫藤安静 | `#4C1D95` | `#FAF5FF` | `#7C3AED` | `#DDD6FE` | 安静、清晰的分类识别 |
| 黑白打印 | `#111827` | `#FFFFFF` | `#334155` | `#94A3B8` | 黑白打印机或节省彩墨 |

应用预设后应给出简短状态反馈，例如“已应用‘薄荷清新’，可继续单独微调颜色”。单独修改任一颜色后，不必强制显示“自定义主题”，但预设卡不再标记为完全选中。

### 4.2 分类专属色盘

每个颜色字段保留四部分：当前色块、HEX 输入框、恢复该字段默认色按钮、专属常用色盘。色盘按钮必须有颜色名称、选中状态和键盘焦点样式。

| 字段 | 推荐色盘 | 设计原则 |
| --- | --- | --- |
| 文字颜色 | `#0F172A`、`#1E3A8A`、`#065F46`、`#7C2D12`、`#581C87`、`#334155` | 只提供深色，保证文字清晰度 |
| 外框颜色 | `#475569`、`#2563EB`、`#0F766E`、`#C2410C`、`#7C3AED`、`#334155` | 中等饱和度，形成清晰边界但不压过文字 |
| 内框颜色 | `#94A3B8`、`#BFDBFE`、`#99F6E4`、`#FED7AA`、`#DDD6FE`、`#CBD5E1` | 与外框对应的低饱和色，保持层级克制 |
| 纯色背景 | `#FFFFFF`、`#F8FAFC`、`#EFF6FF`、`#F0FDFA`、`#FFFBEB`、`#FFF7ED`、`#FAF5FF` | 只提供浅色，适合纸张打印与深色文字 |

原生颜色选择器仍作为自定义入口；HEX 输入在失焦或 Enter 时校验并规范化为 6 位十六进制值。无效 HEX 不覆盖最后有效颜色，并显示字段级错误。

## 5. 数据模型、渲染与本地草稿

### 5.1 外边框统一宽度

`LabelAppearance` 删除以下已废弃字段：

- `outerBorderUniform`
- `outerBorderWidths`

保留并唯一使用 `borderWidthMm`。`LabelPageCanvas` 删除逐边宽度分支和 `getOuterBorderWidths()`，改为基于同一 `borderWidthMm` 生成四边 padding；外框不可见时四边均为 `0 mm`。

`DEFAULT_APPEARANCE`、恢复默认样式、预览/打印渲染、类型测试和文档均应同步更新。读取旧版本本地草稿时必须忽略残留的逐边字段，保留兼容的 `borderWidthMm`；保存新草稿时不再写入已废弃字段。

### 5.2 颜色配置

新增 feature 内纯数据配置，例如 `utils/appearancePresets.ts`：

- `LABEL_COLOR_PRESETS`：预设名称、四个颜色字段和说明。
- `APPEARANCE_COLOR_SWATCHES`：按文字、外框、内框、背景分组的色盘及无障碍名称。
- 可选的 `getContrastRatio()`：仅计算文字与纯色背景的对比度。

配色预设不新增 `LabelAppearance` 字段；应用时通过现有 `updateAppearance()` 更新四个颜色字段，因此现有本地草稿格式和打印链路不需要新增状态。

## 6. 组件拆分与文件范围

建议保留 `LabelContentPanel.tsx` 作为页面级组合与“恢复默认样式”入口，把复杂配置下沉到 feature 专属组件。建议目录如下：

```text
apps/web/src/features/label-printing/
├── components/
│   ├── LabelContentPanel.tsx                 # 标题、预设、单开分类容器
│   ├── AppearanceSection.tsx                 # 可访问的分类标题与内容区域
│   ├── TypographySettingsSection.tsx
│   ├── OuterBorderSettingsSection.tsx
│   ├── InnerBorderSettingsSection.tsx
│   ├── BackgroundSettingsSection.tsx
│   ├── AppearanceColorField.tsx               # 色块、HEX、恢复、分类色盘
│   └── LabelBackgroundEditor.tsx              # 复用并在背景分类中挂载
├── utils/
│   ├── appearance.ts                          # 保留物理常量与颜色规范化
│   └── appearancePresets.ts                   # 配色预设、色盘、对比度工具
├── types.ts                                   # 删除逐边外框字段
├── utils/templatePresets.ts                   # 更新默认外观
├── stores/useLabelPrintingStore.ts            # 旧草稿兼容与恢复默认
└── components/LabelPageCanvas.tsx             # 统一外框渲染
```

可复用的通用 UI 保持在 `apps/web/src/components/ui/`；上述组件属于姓名贴业务，不应移入通用 UI 目录。

6. 接入纯色/图片背景切换，确保图片、遮罩、定位和本地持久化边界不回归。
7. 完成组件测试、响应式检查、预览/打印回归和文档同步。

## 8. 测试与验收

### 自动化测试

- 外框宽度始终同步作用于四边；关闭外框后四边不留额外占位。
- 旧本地草稿含 `outerBorderUniform` 或 `outerBorderWidths` 时可正常恢复，且新保存结果不含这两个字段。
- 四个分类一次只能展开一个；默认展开字体分类；键盘可操作并正确更新 `aria-expanded`。
- 外框、内框关闭后对应渲染消失，重新开启后保留之前的颜色、宽度或线型。
- 点击配色预设只更新四种颜色，不清除背景图片、不改变字号、圆角或边框显示状态。
- 单项颜色恢复、HEX 校验、色盘选中状态、低对比度提示均有覆盖。
