# 姓名贴性能基线

## 测量范围

使用 10,000 条合成姓名（不含真实学生数据）测量“文本清洗 + 默认模板分页”。测试位于 `apps/web/src/features/label-printing/services/nameLabelPerformance.test.ts`。

## 当前结果

2026-08-29 在本地 Vitest 环境执行：测试主体耗时约 77ms（单测报告显示 74ms），成功生成 193 页。该结果低于计划中 100ms 的可感知阻塞阈值，因此当前不引入 Worker，避免增加数据复制、取消和失败恢复的复杂度。

XLSX 解析仍通过 `read-excel-file@9.3.10` 动态加载，优先使用兼容入口，失败后尝试浏览器入口，并保留 5MB、10,000 行、100 列和 80 字符限制。姓名数据不跨页面生命周期持久化或上报。

## 2026-09-14 复测

在同一工作树的 Vitest 环境中，`nameLabelPerformance.test.ts` 报告测试主体约 61ms，成功生成 193 页；测试保留 `<1000ms` 断言。本次新增的 direct Scene→PDF benchmark 使用 ASCII 文本：1/20/100/200 页约 470.8/372.0/1714.5/3228.0ms，文件约 3.6/56.9/281.3/562.0 KiB；未测峰值内存、CJK 字体和图片场景，不作为跨机器 SLA。
